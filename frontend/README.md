# Frontend — AI Exam System

React + Vite frontend for the AI Driven Accessible Examination System.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint
```

The dev server proxies `/api` to the FastAPI backend at `http://localhost:8000`.

See the [root README](../README.md) for full setup instructions, features, and API documentation.
